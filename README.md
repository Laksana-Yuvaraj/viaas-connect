# viaas-connect
VIAAS-CONNECT is a smart campus app built for Vivekanandha Arts and Science College for Women (VIAAS), Sankari, to centralize day‑to‑day academic and administrative activities for students, staff, and administrators.​
The app follows a spiral development model and offers separate dashboards for admins, principal/IQAC, staff, and students, covering core modules like authentication, departments and classes, attendance, semester tracking, syllabus coverage, internal marks, notifications, and basic LMS features such as assignments and “Your Class” views.​
It aims to replace scattered manual processes with a structured digital workflow for VIAAS, aligning with the college’s multi‑programme structure and student‑centric services.
The app includes secure login with role‑based access, multi‑department and class management, hourly and daily attendance, staff and student profiles, semester and syllabus tracking, internal marks and reports, simple LMS pages for notes and assignments, and support for email/SMS style notifications and future AI‑assistant integration using LLM APIs.
